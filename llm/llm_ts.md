
# LLM for Time Series



# REF

- [Time-LLM](https://github.com/KimMeen/Time-LLM)
- [timesfm](https://github.com/google-research/timesfm)  Google Research 时序基础模型（200M 参数，decoder-only） 持续更新中
- [timecopilot](https://github.com/TimeCopilot/timecopilot)  结合了 30 多个时间序列基础模型（Chronos、Moirai、TimesFM、TimeGPT 等）与 LLM 推理能力，实现自动化的模型选择和解释。
